# 台本作成コマンド

$ARGUMENTS にクライアント名が指定されていればそれを使う。なければヒアリングから始める。

## ステップ1：ヒアリング（必須・最初に必ずやる）

`clients.md` を読み込んでクライアントの基本情報を把握した上で、以下を**ユーザーに質問する**。
一度に全部まとめて聞く（何度も往復しない）。

---

**以下を教えてください：**

1. **クライアント**：どのアカウント？（複数ある場合）
2. **コンテンツの内容・テーマ**：今回何を伝えたい？どんな出来事・エピソード・情報？
3. **伝えたいこと・メッセージ**：視聴者に最終的に何を感じてほしい・思ってほしい？
4. **目的**：フォロワー増加 / 認知拡大 / 商品・サービスのPR / 信頼構築 / その他？
5. **PRしたいものがあれば**：何をどう繋げたい？（なければ「なし」でOK）

---

ユーザーの回答を待つ。回答が来たら次のステップへ進む。

## ステップ2：構成の提案（台本を書く前に確認を取る）

ヒアリング内容と `clients.md` のクライアント情報をもとに、以下を提案して確認を取る：

```
【フック案】
"（最初の1〜3秒で言うセリフ・テロップ案を2〜3パターン）"

【共感パート】
視聴者のどんな感情・状況に刺さるか

【回収・オチ】
どう真実を明かしてPRに繋げるか

この方向で台本を書いていいですか？
修正があれば教えてください。
```

ユーザーの確認・修正を受けてから次のステップへ。

## ステップ3：台本の初稿作成

確定した構成をもとに台本を書く。

**基本ロジック：**
```
誤解（強いワードで惹きつける）
  ↓
共感（視聴者の気持ちを代弁）
  ↓
回収（真実を明かして納得・PRへ繋げる）
```

**フォーマット：**
- 尺：60〜90秒想定
- セリフ＋ト書き（カメラ指示・テロップ案）を含める
- 冒頭3秒のフックを特に意識する

## ステップ4：第三者レビュー（サブエージェント）

初稿を書いたら、**必ずAgentを呼び出して第三者レビューを実施する**。ユーザーへの提示より先に行う。

```javascript
Agent({
  description: "台本の第三者レビュー",
  prompt: `
あなたはInstagramのリールをよく見る一般の視聴者です。
プロのSNSコンサルタントではなく、「普通にスマホを見ている人」として評価してください。

【クライアント・コンテンツ情報】
（クライアント名・演者・ターゲット層・今回の目的・伝えたいメッセージ）

【台本（初稿）】
（作成した台本をここに記載）

以下の観点で、忖度なしに率直に評価・ダメ出ししてください：

**① フック力（最初の1〜3秒）**
- スクロールを止めたいと思ったか？
- 最初のセリフ・テロップは魅力的か？

**② 共感度**
- 「わかる」「自分のことだ」と感じる部分はあったか？
- 逆に「そんなわけない」「大げさ」と感じた部分は？

**③ 視聴継続意欲**
- 最後まで見たいと思えるか？
- 途中で飽きる・離脱したくなる箇所はどこか？

**④ セリフ・表現の違和感**
- 不自然な言い回し、くどい部分、わかりにくい部分はないか？
- 「こんなこと言わないよ」と感じる台詞はないか？

**⑤ PR・オチの自然さ**
- 商品・サービスへの繋ぎは押し付け感がないか？
- オチは納得感があるか？

**⑥ 総合評価**
- 100点満点でのスコア
- 「バズりそう」か「スルーしそう」か、正直な感想
- 最優先で直すべき1〜3点の改善案

遠慮なく厳しく評価してください。
  `
})
```

## ステップ5：修正・最終版の提示

レビュー結果をもとに台本を修正し、ユーザーに以下の形式で出力する：

```
---
## 第三者レビューの評価
（サブエージェントの評価サマリーをここに記載）

## 修正ポイント
- （レビューを受けて変えた箇所を箇条書きで）

## 台本【最終版】
（修正済みの台本）
---
```
