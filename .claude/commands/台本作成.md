# 台本作成コマンド

$ARGUMENTS で指定されたクライアント（またはテーマ）の台本を作成し、第三者レビューを経て最終版を提示する。

## 実行手順

### 1. クライアント情報の確認

`clients.md` を読み込み、指定クライアントの以下を把握する：
- 演者・属性
- ターゲット層
- コンセプト・トーン
- 過去の成功パターン（あれば）

### 2. 台本の初稿作成

基本ロジックに沿って台本を作成する：

```
誤解（強いワードで惹きつける）
  ↓
共感（視聴者の気持ちを代弁）
  ↓
回収（真実を明かして納得・PRへ繋げる）
```

台本フォーマット：
- 尺：60〜90秒想定
- セリフ＋ト書き（カメラ指示・テロップ案）を含める
- 冒頭3秒のフックを特に意識する

### 3. 第三者レビュー（サブエージェント）

以下のAgentを呼び出してレビューを実施する：

```javascript
Agent({
  description: "台本の第三者レビュー",
  prompt: `
あなたはInstagramのリールをよく見る一般の視聴者です。
プロのSNSコンサルタントではなく、「普通にスマホを見ている人」として評価してください。

【クライアント情報】
（クライアント名・演者・ターゲット層をここに記載）

【台本（初稿）】
（作成した台本をここに記載）

以下の観点で、忖度なしに率直に評価・ダメ出ししてください：

**① フック力（最初の1〜3秒）**
- スクロールを止めたいと思ったか？
- 最初のセリフ・テロップは魅力的か？

**② 共感度**
- 「わかる」「自分のことだ」と感じる部分はあったか？
- 逆に「そんなわけない」「大げさ」と感じた部分は？

**③ 視聴継続意欲**
- 最後まで見たいと思えるか？
- 途中で飽きる・離脱したくなる箇所はどこか？

**④ セリフ・表現の違和感**
- 不自然な言い回し、くどい部分、わかりにくい部分はないか？
- 「こんなこと言わないよ」と感じる台詞はないか？

**⑤ PR・オチの自然さ**
- 商品・サービスへの繋ぎは押し付け感がないか？
- オチは納得感があるか？

**⑥ 総合評価**
- 100点満点でのスコア
- 「バズりそう」か「スルーしそう」か、正直な感想
- 最優先で直すべき1〜3点の改善案

遠慮なく厳しく評価してください。
  `
})
```

### 4. 修正・最終版の提示

レビューのフィードバックをもとに台本を修正し、以下の形式で出力する：

```
## 修正ポイント（レビューを受けて変えた箇所）
- ...

## 台本【最終版】
...
```
